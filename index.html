1. Podstawy funkcji w Kotlinie

Funkcje w języku Kotlin definiujemy za pomocą słowa kluczowego fun. Każda funkcja może przyjmować parametry i zwracać wartość.

Struktura funkcji:

fun nazwaFunkcji(parametr: Typ): TypZwracany {
    return wynik
}

Przykład:

Poniżej znajduje się funkcja, która dodaje dwie liczby całkowite (Int) i zwraca ich sumę:

fun dodaj(a: Int, b: Int): Int {
    return a + b
}
